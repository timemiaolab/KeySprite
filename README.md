
小工具 KeySprite，主要想省掉两个经常重复的操作：复制文件路径，以及打开终端后再 cd 到目标目录。

### 功能很简单：
- 计算文件sha256 和 md5
- 复制文件或文件夹的绝对路径：选中多个时，用换行分隔；没有选中时，复制当前目录。
- 打开终端并定位目录：选中文件夹就进入该文件夹，选中文件就进入它所在的目录。

### 默认快捷键（可自定义）
- [command + 8] sha256 和 md5 
- [command + 9] 复制路径
- [command + 0] 打开终端
