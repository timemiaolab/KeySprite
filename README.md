小工具 KeySprite，主要想省掉几个经常重复的操作：计算文件 SHA256 和 MD5、复制文件路径，以及打开终端后再 cd 到目标目录。

### 功能很简单：
- 计算选中文件的 SHA256 和 MD5（不支持文件夹），并复制到剪贴板。
- 复制文件或文件夹的绝对路径：选中多个时，用换行分隔；没有选中时，复制当前目录。
- 打开终端并定位目录：选中文件夹就进入该文件夹，选中文件就进入它所在的目录。

### 默认快捷键（可自定义）
- macOS：[Command + 8] SHA256 和 MD5；[Command + 9] 复制路径；[Command + 0] 打开终端
- Windows / Linux：[Alt + 8] SHA256 和 MD5；[Alt + 9] 复制路径；[Alt + 0] 打开终端
